# 🤖 Garland TG Bot

Мой первый Telegram-бот, демонстрирующий работу с машиной состояний, базой данных, инлайн-кнопками и внешним API.

## 📋 Возможности

- Регистрация пользователя с пошаговым вводом данных (FSM)
- Просмотр своих данных из базы данных
- Удаление своих данных
- Панель администратора с просмотром всех пользователей
- Инлайн-кнопки и команды
- Валидация вводимых данных на каждом шаге
- Курсы валют в реальном времени через ExchangeRate API (USD, EUR, RUB, JPY, GBP, CNY, CAD, AUD)

## 🛠 Стек

- **Python 3.11+**
- **aiogram 3.x** — асинхронный фреймворк для Telegram ботов
- **SQLite** — база данных
- **ExchangeRate API** — курсы валют в реальном времени
- **python-dotenv** — управление переменными окружения

## 🚀 Запуск

1. Клонируй репозиторий:
```bash
git clone https://github.com/твой_ник/твой_репо.git
cd твой_репо
```

2. Установи зависимости:
```bash
pip install aiogram python-dotenv requests
```

3. Создай файл `.env` и добавь токены:
TELEGRAM_TOKEN=твой_токен
ADMIN_IDS=твой_id
API_TOKEN=твой_токен_exchangerate([text](https://www.exchangerate-api.com/))

4. Запусти бота:
```bash
python main.py
```

## 💡 Чему научился
