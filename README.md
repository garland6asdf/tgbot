# 🤖 Garland TG Bot

Мой первый Telegram-бот, демонстрирующий работу с машиной состояний, базой данных и инлайн-кнопками.

## 📋 Возможности

- Регистрация пользователя с пошаговым вводом данных (FSM)
- Просмотр своих данных из базы данных
- Удаление своих данных
- Панель администратора с просмотром всех пользователей
- Инлайн-кнопки и команды
- Валидация вводимых данных на каждом шаге

## 🛠 Стек

- **Python 3.11+**
- **aiogram 3.x** — асинхронный фреймворк для Telegram ботов
- **SQLite** — база данных

## 🚀 Запуск

1. Клонируй репозиторий:
```bash
git clone https://github.com/твой_ник/твой_репо.git
cd твой_репо
```

2. Установи зависимости:
```bash
pip install aiogram
```

3. Создай файл `cfg.py` и добавь токен:
```python
TOKEN = "твой_токен"
ADMIN_IDS = [твой_id]
```

4. Запусти бота:
```bash
python main.py
```

## 💡 Чему научился

- Работа с FSM (машина состояний) в aiogram 3
- Хранение и получение данных через SQLite
- Разделение логики по роутерам и хэндлерам
- Валидация пользовательского ввода
- Разграничение прав: пользователь и администратор
